# En Passant Club Journey

A responsive React timeline showcasing the journey of En Passant Chess Club at ABES EC.

## Features

- Full-screen chess themed hero section
- Nine club milestones
- Six image-based event cards and three compact entries
- Alternating desktop timeline
- Single-column mobile layout
- Scroll-reveal animation
- Hover interactions on event cards
- Responsive typography and spacing

## Tech Stack

- React
- Vite
- CSS
- JavaScript

## Setup

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal.

## Production Build

```bash
npm run build
```

## Preview Production Build

